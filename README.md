# مبسّط: ابنِ تطبيقك بالكلام

منصة فايب كودنق عربية: المستخدم يكتب وصف التطبيق، والمساعد يكتب الكود ويشغّله في
بيئة معزولة (Vercel Sandbox) مع معاينة مباشرة وسجل تنفيذ وعرض للملفات.

مبنية على قالب Vercel المفتوح المصدر
[`vercel/examples/apps/vibe-coding-platform`](https://github.com/vercel/examples/tree/main/apps/vibe-coding-platform)
(رخصة MIT، النص في `LICENSE.vercel.md`)، مع هذه الإضافات:

- واجهة عربية كاملة باتجاه من اليمين لليسار وخط IBM Plex Sans Arabic.
- المساعد يرد بالعربي، ويبني التطبيقات افتراضيًا بالعربي وRTL والأسعار بالريال.
- النموذج الافتراضي Claude Opus 5، مع Claude Sonnet 5 كخيار أرخص.
- بوابة دخول برموز دعوة (`ACCESS_CODES`) تحمي رصيد النماذج وبيئات التشغيل.

## الإطلاق على Vercel

1. في Vercel: **Add New → Project** واستورد هذا المستودع.
2. تأكد إن **AI Gateway** و**Sandbox** مفعّلة على حساب Vercel وفيها رصيد. على
   Vercel تتم المصادقة تلقائيًا عبر OIDC، فما تحتاج مفتاح AI Gateway.
3. أضف متغير البيئة `ACCESS_CODES`: رموز دعوة مفصولة بفواصل، طويلة وعشوائية
   (مثلًا `openssl rand -hex 12` لكل رمز). بدونه ما أحد يقدر يدخل في الإنتاج.
4. انشر، ثم اربط نطاقًا فرعيًا (مثل `build.mubasatplatform.com`) من إعدادات
   النطاقات في المشروع، وأضف سجل CNAME اللي يطلبه Vercel في DNS.
5. ضع حد صرف وتنبيهات على AI Gateway قبل ما توزّع الرموز.

إلغاء رمز من `ACCESS_CODES` يطلّع كل من دخل فيه.

## التشغيل المحلي

```bash
cp .env.example .env.local   # ضع AI_GATEWAY_API_KEY
pnpm install
pnpm dev
```

محليًا، إذا ما ضبطت `ACCESS_CODES` تكون البوابة مفتوحة.

## حدود النسخة الحالية

- التطبيق المبني يعيش داخل بيئة التشغيل فقط (10 إلى 45 دقيقة) ثم يختفي. لا يوجد
  حفظ للمشاريع ولا نشر للتطبيقات المبنية بعد.
- لا توجد حسابات مستخدمين ولا رصيد لكل مستخدم: الحماية الحالية هي رموز الدعوة
  وحد الصرف على AI Gateway.

## الخطوات التالية

1. نشر التطبيق المبني على نطاق فرعي عبر Vercel SDK.
2. حسابات المستخدمين وحفظ المشاريع.
3. نظام رصيد واشتراكات مدفوعة عبر EdfaPay.
4. وحدات سعودية جاهزة داخل القوالب: الدفع، واتساب، الفوترة الإلكترونية.
